📖 TGFS Instructions & Help

🧩 How TGFS Is Different From PLGB

🤖

Multi-bot

The TGFS bot can run several Telegram bot tokens at once (a main bot plus extra "worker" bots). Every link is tagged with the numeric Bot ID of whichever bot generated it, and every entry on the Review/Done pages shows its Bot ID so you know which bot's user asked for it. Use the Bot ID search field to filter by a single bot (or exclude one with a negative id, e.g. -123).

🗄️

Multi-database (index/blob split)

TGFS can spread its data across several MongoDB deployments ("clusters"). Each uploaded file's metadata (name, size, MIME type, and whether it's restricted) lives in a "blob" cluster, while each user's individual link to that file lives separately in an "index" cluster. A single physical file can be linked by more than one user. This review tool automatically joins both sides together for every entry you see; Accept/Reject decisions apply to the underlying file (so they affect every link to it), while Delete only removes the specific link you deleted — the underlying file is only cleaned up once no link references it anymore.

🔗

Download / Watch links

Unlike PLGB's plain /dl/<id>/<name> links, TGFS signs every link with an HMAC secret shared with the running bot, so the DL/Watch buttons on each card always produce a valid, working link against the live server.

🔍 Search Filters

🎯

User ID / Bot ID Search

  • Positive ID (e.g. 123): Show only entries for that user/bot
  • Negative ID (e.g. -123): Exclude that user/bot, show everyone else
  • User ID also accepts a comma-separated list (e.g. 123,456) to show entries from any of those users (OR'd together); an all-negative list excludes all of them instead.
  • Leave empty to search across all users/bots
📂

File Name Search

  • Enter one or more keywords
  • ALL words must be present in the file name (AND logic)
  • Case-insensitive partial match
👤

Forwarded From

  • Searches the forwarder's name and username
  • Matches either field (OR logic)
  • Case-insensitive partial match
📏

File Size Range

  • Set a minimum and maximum size in MB
  • Range: 0 – 4200 MB
  • Leaving it at full range (0–4200) disables this filter
🆔

Telegram File ID

Search for the exact numeric Telegram file id (shown as "File ID" on every card) instead of a Mongo document hash.

📊 Search Statistics Panel

When you apply any search filter, a statistics panel appears on the right side of the Review page. It shows:

📈
  • Total matching links
  • Pending reviews remaining
  • Accepted / Rejected counts
  • Review progress percentage
  • Acceptance & rejection rates

For very broad filters (e.g. no filter at all), these counts are capped at a large working-set size per database cluster rather than scanning every document, to keep the page fast — this only matters on very large deployments.

✅ Review Workflow

1️⃣

Load files

Open the Review page. Without any filter it loads random pending (never-reviewed) links. Use the Advanced Search to narrow down by user, bot, name, size or date.

2️⃣

Preview before deciding

Each card has DL (download) and Watch buttons that build a working signed link against the live TGFS server.

3️⃣

Rename if needed

Click the file name box at the top of any card to edit it. The new name is saved to both the file's record and its link on submission.

4️⃣

Accept, Reject, Delete, or Delete & Warn

  • Accept — marks the file as unrestricted (downloadable).
  • Reject — restricts the file (downloads return "File is restricted").
  • Delete — permanently removes this link. The underlying file is only deleted once no other link references it.
  • Delete & Warn — same as Delete, plus increments the uploader's warn count. Banning at a warn threshold is handled by the TGFS bot itself, not by this tool.
5️⃣

Submit

Click Review Summary & Submit to preview all your decisions (including any renames), then confirm to write them to the database.

✏️ Regex Rename

The Review page's Regex Rename box works the same way as on the PLGB Review page — enter a Pattern (what to find) and Replace with (what to put instead) to batch-rename every visible file at once. See the PLGB Instructions page for a full cheat-sheet of examples.

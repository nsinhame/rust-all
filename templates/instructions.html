📖 Instructions & Help

🔍 Search Filters

🎯

User ID Search

  • Positive ID (e.g. 123): Show only files from that user
  • Negative ID (e.g. -123): Exclude that user, show everyone else
  • Leave empty to search across all users
📂

File Name Search

  • Enter one or more keywords
  • ALL words must be present in the file name (AND logic)
  • Words can appear in any order
  • Case-insensitive partial match
👤

Forwarded From

  • Searches across all four forward fields at once
  • Forward First Name, Forward Username, Forward Chat Title, Forward Chat Username
  • Matches any one of them (OR logic)
  • Case-insensitive partial match
📏

File Size Range

  • Use the dual slider to set a minimum and maximum size
  • Range: 0 – 4200 MB
  • Leaving it at full range (0–4200) disables this filter
✨

Combined Search

  • All filters can be combined freely
  • Each active filter is ANDed together
  • Use as many or as few as you need

💡 Examples

Include a specific user
User ID: 1234567890
→ Shows only pending files belonging to user 1234567890
Exclude a specific user
User ID: -1234567890
→ Shows pending files from everyone except user 1234567890
File name keyword search
File Name: mr robot
→ Files whose name contains both "mr" AND "robot" (order doesn't matter)
User + file name combined
User ID: 1234567890
File Name: mr robot
→ Files from user 1234567890 that also contain "mr" AND "robot"
Forward source search
Forwarded From: robot
→ Files where any forward field contains "robot"
Size range only
Size: 500 – 1500 MB
→ Only files between 500 MB and 1500 MB

📊 Search Statistics Panel

When you apply any search filter, a statistics panel appears on the right side of the Review page. It shows:

📈
  • User ID only: User-specific stats for that single user
  • File name only: Stats across all files matching the search query
  • Both combined: Precise stats for that user's matching files
  • Total matching files
  • Pending reviews remaining
  • Accepted / Rejected counts
  • Review progress percentage
  • Acceptance & rejection rates

✅ Review Workflow

1️⃣

Load files

Open the Review page. Without any filter it loads 10 random pending files. Use the Advanced Search to narrow down.

2️⃣

Preview before deciding

Each file card has DL (download) and Watch buttons. Use them to inspect the file before accepting or rejecting.

3️⃣

Rename if needed

Click the file name text box at the top of any card to edit it. The box turns amber when a name has been changed. The new name is saved to the database on submission.

4️⃣

Accept or Reject

Click Accept to make the file public, or Reject to keep it private. You can skip any file by not clicking either button.

5️⃣

Submit

Click Review Summary & Submit to preview all your decisions (including any renames), then confirm to write them to the database.

✏️ Regex Rename — 50 Examples

Use the Regex Rename box on the Review page to batch-rename all visible files instantly. Enter the Pattern (what to find) and Replace with (what to put instead). Leave Replace with empty to simply delete the matched text. Capture groups are written as $1, $2 … in the replacement.

1
Remove @username prefix
Pattern^@\S+\s Replace with(empty)
@Mj_Link Mr Robot S01.mp4 → Mr Robot S01.mp4
2
Replace spaces with underscores
Pattern\s+ Replace with_
My Movie File.mkv → My_Movie_File.mkv
3
Replace underscores with spaces
Pattern_ Replace with (a space)
My_Movie_File.mkv → My Movie File.mkv
4
Remove content in square brackets
Pattern\[.*?\] Replace with(empty)
Movie [720p][BluRay].mkv → Movie .mkv
5
Remove content in round brackets
Pattern\(.*?\) Replace with(empty)
Show (2023) Episode.mp4 → Show Episode.mp4
6
Remove quality tag (720p / 1080p / 4K)
Pattern[\.\s_-]?(720p|1080p|4K|2160p) Replace with(empty)
Film.1080p.mkv → Film.mkv
7
